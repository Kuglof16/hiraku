# Viewer test fixtures

Small run folders trimmed from real records (made 2026-11-06). Each design keeps only its name, nodes, members, sections, materials and a few parts (id, name, kind, module, box, mass).

For the parts layer (common.parts_ledger), the `nvh/` and `crash/` designs also hold the design's four `supports` (copied from the same design: v005 of the demo run for `nvh/`, `data/designs/offroad-4w-v1.json` for `crash/`), and `nvh/` holds two parts of v005 (`battery` with its carried_by nodes, `wheel_FL` without). The parts are fewer than the run weighed, so the record's mass and the mass computed here do not agree on these fixtures (the page shows the difference).

- `nvh/`: the modal record (N1-40kmh) of version v005 of the scripted demo run `20261106-081501-offroad-4w-scripted`. The first 3 mode shapes are kept, with the frequency response at 50 points. `project.json` holds only that load case.
- `crash/`: a C1 run made for the viewer. It is the `crash` tool on `data/designs/offroad-4w-v1.json`, with the C1 load case from the catalog builders (`data/requirements/offroad-4w.yaml`, C1-40kmh). The series are kept at 40 points, and the design at 8 parts.
- `crash_b/`: a C1 run made for the viewer (2026-11-06) with K2's `crash_beam` tool (branch claude/k2-crash-beam-b, 182f148f, not in main yet: the run stops when a piece breaks off the seats' side, members' axial force and end hinges, hot spots) on `data/designs/offroad-4w-v1.json` with the catalog's C1-40kmh load case. The node_motion field keeps every 6th of its 122 frames and the last (22), and the member series (at the node_motion times) the same frames; the deceleration and crush series every 3rd point, the last and the peak. The design keeps 8 parts with carried_by.
- `thermal/`: runs made for the viewer (2026-11-06) on `data/designs/offroad-4w-v1.json` with the catalog's load cases: `thermal` with T1-40C (ana-0001) and `drive_energy` with P4-20km (ana-0002) in one version folder. Series every 12th point and the last; the design keeps its nodes, members, sections, materials, supports, variables and the parts of kind battery, motor, controller, reducer, wheel and cargo.
- `fatigue/`: a `fatigue` run with R3-5000km-C on the same design (2026-11-06). Time series every 15th point and the last, the scene's road every 8th point; parts of kind battery, wheel, cargo.
- `strength_beam/`: the frame_static record ana-0083 (R1-step100) of v005 of the scripted demo run `20261106-081501-offroad-4w-scripted`, without its per_element surface field; `project.json` holds only that load case; the design keeps 8 parts.
- `strength_shell/`: from the frames a step-hit frame_shell run saved for the bracket set b90 (design v005 + its variables, 10 mm mesh): the elements of rail_L_HB, rail_L_BE and the LB tower posts (6210 quads), the hot instant and its two neighbours, the weld lines of LB and LE, and the RL mounts' load paths (their first 20 nodes). `load_paths.json` names the design as plain "v005" so the trimmed design is used as it is; `v005/design.json` is the strength_beam design.
- `assembly/`: the H1-interference assembly record of v001 of the scripted run `runs/20261103-013318-offroad-4w-scripted` (19 steps, 4 motion interferences), with the parts its steps and interferences name.
