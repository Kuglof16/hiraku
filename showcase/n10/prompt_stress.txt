4 輪の電動の小型車のフレームについて教えてください。

フレーム (はしご形、鋼の角パイプを溶接):
- 座標: x は前向き、y は左向き、z は上向き (mm)。原点は前の車軸の真ん中の真下の地面
- 左右のレール: y = +350 と y = -350、高さ z = 380。x = +400 から x = -2100 まで 1 本ずつ通す。断面は幅 40 × 高さ 80 × 厚さ 2.3 の角パイプ
- 横の部材: x = +400、0、-450、-1000、-1700、-2100 の 6 か所で左右のレールをつなぐ。断面は 40 × 40 × 2.3 の角パイプ
- 材料: STKR400 (ヤング率 205,000 MPa、ポアソン比 0.3、密度 7,850 kg/m^3)。フレームの重さ 32.3 kg も荷重に入れる
- つなぎ目は剛 (溶接)

車輪とサスペンション:
- 前の車軸 x = 0、後ろの車軸 x = -1700。車輪の中心は y = ±550、z = 300 (半径 300)
- 各輪の力は、作用する点から、その車軸の位置のレールの点 (前は x = 0、後ろは x = -1700 の、同じ側のレール) に、点のずれの分のモーメントごと伝わる (サスペンションの腕は剛とみなす)

載っているもの (重さは、書いたレールの点 (x の位置、左右とも) に等分にかかる。重心の位置のずれの分のモーメントも伝わる):
- 電池 50 kg、重心 (-725, 0, 330)、x = -450 と -1000 の 4 点
- モーター 25 kg、(-1550, 0, 310)、x = -1700 の 2 点
- 制御器 4 kg、(-1110, 0, 300)、x = -1000 の 2 点
- 電装 6 kg、(-300, 0, 300)、x = 0 と -450 の 4 点
- 前の床 6 kg、(-225, 0, 440)、x = 0 と -450 の 4 点
- 床 8 kg、(-725, 0, 440)、x = -450 と -1000 の 4 点
- 荷台 18 kg、(-1625, 0, 440)、x = -1000、-1700、-2100 の 6 点
- 前の車体 15 kg、(220, 0, 570)、x = +400 と 0 の 4 点
- ハンドルまわり 12 kg、(-250, -200, 750)、右のレールの x = 0 と -450 の 2 点
- 座席 12 kg × 2、(-725, ±300, 580)、それぞれ同じ側のレールの x = -450 と -1000 の 2 点
- 乗る人 76.6 kg × 2、(-780, ±300, 970)、それぞれ同じ側のレールの x = -450 と -1000 の 2 点
- 荷物 150 kg、(-1625, 0, 600)、x = -1000、-1700、-2100 の 6 点
- 合計 (車輪とサスペンションを含む) 591.5 kg、全体の重心 (-1014, -4, 593.5)

場面: この車が、高さ 100 mm の段差に、左右の前輪で同時にゆっくり乗り上げます (後輪駆動)。前輪が地面から離れて段の角に乗った瞬間、車輪にかかる外からの力は次のとおりです (N)。
- 左前輪: 段の角 (x = +224、z = 100) から、後ろ向き 1,082、上向き 968
- 右前輪: 段の角 (x = +224、z = 100) から、後ろ向き 1,104、上向き 987
- 左後輪: 地面 (x = -1700、z = 0) から、上向き 1,912、前向き (駆動) 1,093
- 右後輪: 地面 (x = -1700、z = 0) から、上向き 1,934、前向き (駆動) 1,093

このとき、フレームに生じるいちばん大きい応力 (曲げ・軸力・ねじりを合わせた相当応力) は何 MPa で、どの部材のどのあたりですか。数字を 1 つと、短い根拠を答えてください。
