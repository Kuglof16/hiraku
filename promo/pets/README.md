# HIRAKU のペット (3D)

HIRAKU のエージェントの役ごとのキャラ (ペット) を three.js で 3D にしたものと、見ながら直すための専用ビューアです。版は v3 (v2 から: 10 体が同じ丸い体だったのを、役ごとに「その分野の解析の結果の見え方」をそのまま体にした。凡例の題も役ごとの量の名前にした)。

| ファイル | 中身 |
|---|---|
| `pet3d.js` | キャラの組み立て。ふつうのスクリプト (ES module ではない) で `window.HirakuPets = { ROLES, BODIES, STATES, FRAME, BANDS, STOPS, BAND_COLORS, LOAD, PROP_MASS, loadFactor, create(THREE, opts) }` を出す。three は呼ぶ側が渡す。`create` の返す物は `update(t, state, camera)` のほかに `contour(t, state)` (量の名前・節点の値の最大と最小・凡例に出す行) と `body` (体の種類・量の名前・説明) を持つ。強度信頼性だけは `field` (節点の座標と値と荷重) も持つ |
| `viewer.html` | 専用のビューア。three r170 と OrbitControls・RoomEnvironment を jsDelivr から読み、`pet3d.js` に渡す |

平面の絵 (`promo/screens/pets.js`、動画 N00 で使用) はそのまま残してあり、ここでは参考にしただけです。

## 役ごとの体

どの体も、目 (白に黒い瞳)・アンテナと役の色の玉・短い足・腕・右手の小道具は同じで、背丈もそろえています (試験で、体の高さが 10 体の真ん中の値から 12 % 以内であることを見ている)。

| id | 名前 | 体の種類 (`kind`) | 何の解析の絵か | 色の量 (凡例の題) | 状態での動き |
|---|---|---|---|---|---|
| `lead` | まとめ役 | `quad-sphere` | 四角の要素の素直な球。内圧を受けた球殻 | 相対の応力 (自重) | 解析中は内圧が増分で上がる。食い違いは左足に体重が偏る |
| `designer` | 設計役 | `cad-surface` | CAD のなめらかな面 (超楕円体) に、パラメータの線 (u 8 本・v 6 本) と寸法の線 (高さと幅)。メッシュではない | 曲率 (相対) | 解析中は形のパラメータ n が動き、角の丸みと曲率が変わる。食い違いは高さの寸法が赤くずれる |
| `packager` | パッケージ役 | `assembly` | 箱の部品 3 つをボルト 4 本で組んだ組立。少し分解した隙間 | 部品どうしの近さ (相対) | 解析中は分解と組立をくり返す (隙間 0.08 ⇄ 0.38)。食い違いはふたが本体に食い込む |
| `cae.handling` | 操安 | `multibody` | 剛体 2 つ (車台と上の箱) を球ジョイントとばね 2 本でつないだマルチボディ。足もとに走った軌跡の線とヨーの回転の矢印 | ロールの振れ (相対) | 上の箱がロールし、車台がヨーする。解析中はスラロームで振れが大きく速い。食い違いは振れが大きく矢印が逆に回る |
| `cae.powertrain` | 動力 | `cell` | 円柱の電池のセル。上の + 端子から、ふたの上を広がり、壁を下りる電流の線 | 電流密度 (相対) | 解析中は電流を上げていき、線が速くなる。食い違いは右の壁に電流が集まる |
| `cae.aero` | 空力 | `flow` | 流体でできた半透明のしずく形の体 (鼻先は小道具の側、尾は左)。表面を流線が尾へ流れ続け、まわりにも流線が回り込む | 速さ (相対) | 解析中は流れの線が速い。食い違いは肩の後ろではく離し、後ろの流れが逆に回る |
| `cae.crash` | 衝突 | `crushed-shell` | 衝突の解析の殻の要素のメッシュ。前 (顔の側) が縮み、横が 2 つのこぶに座屈し、前の板がくしゃっと潰れる | 塑性ひずみ (相対) | 解析中は潰れが 0 から 100 % へ進む。食い違いは右に偏って潰れる |
| `cae.strength` | 強度信頼性 | `stress-solid` | 三角の要素の角ばった塊 (v2 の体を箱に寄せた形)。荷重の矢印 (右腕の付け根) と拘束の三角 (足もと) | 相対の応力 | 解析中は荷重が 10 回の増分で上がる。食い違いは体重が左足に偏る |
| `cae.nvh` | 音振 | `mode-shape` | 固有モードで周期的に変形する網目 (変位は誇張)。変形していない元の形を薄い線で重ねる | 変位 (相対) | ふだんは 2 次のモード (横長 ⇄ 縦長) がゆっくり。解析中は振幅が大きくなり速い。食い違いは別のモード (3 つの山) |
| `cae.thermal` | 熱 | `heat` | 下から温まる温度のコンターと等温線 (帯の境の線)、体のまわりに立ちのぼる熱の線 | 温度 (相対) | 解析中は下から温まっていく。食い違いは右の脇に熱だまり |

### 値の出し方 (どれも形を見せるための簡単なモデルで、解いた値ではありません)

値はできるだけ「どこに何がかかっているか」から `pet3d.js` の中で計算しています。数は相対 (0〜1) で、単位は付けません。1.0 より上の所も赤で塗ります。

- まとめ役: 内圧を受けた殻の膜の応力 σ = p r / (2 t) (r は中心からの距離)。許容値 = 最大 ÷ 0.62 で割るので、ほぼ一様な落ち着いた帯になる
- 設計役: 面の法線の変わり方から出した曲率 (となりの点との法線の差 ÷ 距離の平均)。n = 3 の形の最大の 0.85 倍を 1.0 にする
- パッケージ役: いちばん近いほかの部品の箱までの距離 d から max(0, 1 − d / 0.5)。中に入り込んだ所は 1.0 より上
- 操安: ロール (上の箱) とヨー (車台) の回転軸からの距離 × 角度の振れ幅。スラローム (解析中) の最大を 1.0 にする。地面の軌跡の線の色は、軌跡の曲率から出した横加速度
- 動力: ふたの上は I / (2πr) (端子の半径 0.22 で頭打ち)、壁は I / (2πR)。端子のまわりで濃く、壁は一様
- 空力: 表面は U sin θ (θ は面の法線と流れのなす角) × 断面の大きさによる増し (1 + 0.5 (r / r最大)²)。いちばん太い所で 1.5 U になる。まわりの流線は球を過ぎる流れ (ストークスの流れ関数) で道すじと速さを出す。1.5 U を 1.0 にする (遠くの流れは 0.67)
- 衝突: 節点ごとに、要素の辺の伸び縮み (|l / l0 − 1| の平均) × 0.35 と、となりとの法線の角度の変わり方 ÷ 辺の長さ × 0.25 (殻の厚さの代わり) の和。まっすぐ全部潰れたときの 90 % の点を 1.0 にする (上の 1 割は赤)
- 強度信頼性: v2 と同じ。体の重さ 1.0 を左右の足の付け根が半分ずつ受ける / 右手 (小道具の側) は小道具の重さ × 腕の長さ ÷ 0.11 を付け根に受ける (小道具の重さは役ごと 0.24〜0.5) / 左手は腕の重さ 0.06 で同じ式。1 つの荷重の値は 振幅 ÷ (1 + (距離 / 0.45)²)^1.5、体の自重の膜の項は 0.12 × √((1 − y) / (1 + y))。落ち着いた荷重の最大が 1.0 (右腕の付け根)。定数は `LOAD` と `PROP_MASS`
- 音振: 変位 w = A × Y(向き) × cos(2π f t) を法線の向きに足す。Y は 2 次のモード x² − y² (食い違いは 3 次 x (x² − 3y²))。色は各節点のモードの振幅 |Y| × A を、いちばん大きい振幅 0.17 で割った値 (形は揺れ、色は振幅の地図)
- 熱: 定常はフィン (まわりへ放熱) の解 T = cosh(mL (1 − s)) / cosh(mL)、mL = 1.3、s は下からの高さの割合。解析中は下から温める非定常の解 T = erfc(s / (2√(κt)))。食い違いは右の脇に熱だまりを足す

### 塗り方・線

- 節点の値をシェーダーで三角の中で線形に補間し、10 段で切ります (CAE の後処理のバンドのコンター)。四角の要素は 2 つの三角にしますが、対角の線は描きません。設計役は面の分割の線を描かず、パラメータの線だけを描きます
- 流れ・電流・熱・軌跡の線は、管の上を動く破線 (位相 = 道のり × 密度 − t × 速さ) で、色は線の上の値の帯の色です
- 輪郭は裏返した殻 (法線の向きに少し太らせた黒) で描きます。空力の体は半透明なので、中に生成りの芯を入れて輪郭の殻が透けないようにしています

## ビューアの開き方

`viewer.html` をブラウザで開きます (`file://` のままでよい)。three を jsDelivr から読むので、ネットにつながっている必要があります。

- 左の欄で 表示 (並び・1 体・大きさ)、役、状態、地 (生成り・夜)、要素の辺の線・節点のオンオフ、メッシュの細かさ (粗い・細かい)、カメラ (正面・斜め・横)、自動回転、時刻を止める、を切り替えます
- 並びの表示でキャラを押すと、その 1 体の表示に移ります。1 体の表示はドラッグで回せます
- 「大きさ」の表示は、動画 N00 の 1 体の大きさ (184 px) とアプリの一覧の大きさ (48 px) で 10 体を並べた帯です
- 1 体の表示では右上にコンターの凡例 (カラーバー) が出ます。題は役ごとの量の名前 (上の表)、10 段の色 (上が高い) と段の境の値 0.0〜1.0、その状態の説明、節点の値の最大と最小。並び・大きさの表示では出しません
- 右下の「v3」が版の印です

### URL の引数

いまの表示はいつも URL に写っています。同じ URL を開けば同じ絵になります (姿と値は時刻 t と状態だけで決まり、時計や乱数は使いません。乱数は役の id から作った種で、毎回同じです)。

| 引数 | 値 | 既定 |
|---|---|---|
| `view` | `grid` (並び)・`one` (1 体)・`sizes` (大きさの帯) | `grid` |
| `role` | `lead`・`designer`・`packager`・`cae.handling` など (下の表) | `lead` |
| `state` | `idle`・`report`・`pass`・`mismatch`・`working` | `idle` |
| `bg` | `paper` (生成り)・`night` (夜) | `paper` |
| `edges` / `nodes` | `0` で要素の辺の線 / 節点を消す (設計役のパラメータの線は残る) | `1` |
| `mesh` | `coarse`・`fine` | `coarse` |
| `cam` | `front`・`three` (斜め)・`side` | `three` |
| `spin` | `1` で自動回転 (向きは時刻だけで決まる) | なし |
| `orbit` | 1 体の表示でドラッグしたときのカメラ (方位,仰角,距離。ラジアンと単位長) | なし |
| `t` | 時刻 (秒)。あれば時刻を止めてその時刻の姿を描く | なし (動く) |
| `ui` | `0` で左の欄を隠す (書き出し用) | なし |

例: `viewer.html?view=one&role=cae.aero&state=working&bg=night&t=2.35`

書き出し用に `window.petViewer = { ready, seek(t) }` を出しています。`ready` は three を読み終えて最初の絵を描いたら解ける Promise、`seek(t)` は時刻を止めて t の姿を描きます。

## 共通の部分

- 光: 部屋の環境光 (RoomEnvironment)、上からの主光 (柔らかい影)、後ろからの縁の光、体のシェーダーのフレネルの縁の光、足もとの接地の影。色は sRGB で管理し、トーンマップは色を崩しにくい Neutral を使っています
- 線: 要素の辺はシェーダーで重心座標から描き、画面の上で決まった太さ (キャラの大きさに合わせて 0.8〜2.4 px) になります。小さく出るときは辺を薄くし、節点の点を消して、色の帯が読めるようにしています
- 動き (`update(t, state)` は時刻と状態だけで姿が決まる): idle = 上下・呼吸・まばたき・アンテナの揺れ、report = 前に乗り出す、pass = 小さく跳ねて頭の上に ✓、mismatch = 体ごと首をかしげて頭の上に ?、working = 役ごとの体の動き (上の表)・目が小道具を見る。形の変わる体 (衝突・音振・設計役) では、目とアンテナを毎回その時の面の上に置き直します
- 吹き出し (✓ と ?): アンテナの玉より上、少し右に出し、跳ねるときは体と一緒に上がります

## 試験

`promo/tests/test_pets.py`: `pet3d.js` の役が 10 体でアプリの役の id (`hiraku/contract/hiraku.schema.json`) とそろっていること、10 体の体の種類と量の名前がすべて違い、組み立ての関数があり、この README の表に載っていること、色がリポジトリの値と同じこと (コンターの `BANDS`・`STOPS` が `web/js/colormap.js` と同じこと)、強度信頼性のメッシュの細かさ、版の印、姿を決めるところで時計や乱数を使っていないこと。playwright とネットがあるときだけ、ビューアを開いて次も見ます (無ければ飛ばします): `window.petViewer.ready` が解けること、`BAND_COLORS` が `colormap.js` の計算と同じで、凡例が 10 段 (上が高い)・目盛り 11 本で、題が役の量の名前で、並びの表示では凡例が出ないこと、解析中の荷重が 0 から 1 へ増えること、強度信頼性の 2 つの細かさで節点・要素の数、落ち着いた荷重の最大 1.0 が右腕の付け根の節点・てっぺんが 0.15 未満・食い違いの最大が左足の付け根の節点にあること、10 体の体の高さがそろうこと、同じ t と状態で 2 体を作ると形と値が同じになること、どの状態でも凡例の値が有限であること。
