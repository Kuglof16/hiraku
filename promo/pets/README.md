# HIRAKU のペット (3D)

HIRAKU のエージェントの役ごとのキャラ (ペット) を three.js で 3D にしたものと、見ながら直すための専用ビューアです。版は v10 (v10 では、モジュールごとの設計役 6 体 (枠・足まわり・操作系・乗員まわり・動力・車体) を ROLES の最後に足した。体は設計役と同じ CAD のモデルで、持ち場の違いは小道具と色で出す。前からの 10 体の絵は v9 と画素まで同じ。下の「v10: モジュールの設計役」。v9 では、状態「待ち」(`waiting`) と「止められた」(`blocked`) を STATES の最後に足し、小さく出すときの軽い描き方 (`lite`) と描く量を返す `cost()` を足した。lite を付けないときの絵は v8 と画素まで同じ。下の「v9: 待ち・止められた・軽い描き方」。v8 では、パッケージ役を「透明な箱に積み木を詰めた」四角い体に作り直した。三角の数をほかの役と同じくらい (3 万個以下) にし、v7 の組木と輪は `packagerStyle: "burr"`・`"rings"` で残した。ほかの 9 体は v7 のまま。v7 では、パッケージ役を 3 次元で噛み合う立体のパズル (6 本組木) に作り直し、別案として金属の輪 3 つの知恵の輪を `packagerStyle: "rings"` で選べるようにした。ほかの 9 体は v6 のまま。v3 で、役ごとに「その分野の解析の結果の見え方」をそのまま体にした。v4 では、まとめ役を v2 の体に戻し、パッケージ役・操安・動力 (燃焼)・衝突を作り直した。v5 では、設計役を CAD のモデルの見え方 (コンターなし) に、パッケージ役をひとまとまりの組み立て品に、操安をマルチボディ (機構解析) の見え方に、強度信頼性を穴のまわりの応力集中に作り直した。ほかの 6 体は v4 のまま。ビューアはどの向きにも回せる。v6 では、音振のちらつきを止め (揺れを遅く・なめらかに、元の形の線が明滅しない)、空力の色を速さから圧力に、パッケージ役を凹凸で噛み合う 3D のパズルに、操安の真ん中の車体を金属に変え、新しい状態「走る」(`run`) を足した。working の状態の名前を「作業中」に改めた (内部の名前は `working` のまま))。

### 値の出し方 (どれも形を見せるための簡単なモデルで、解いた値ではありません)

値はできるだけ「どこに何がかかっているか」から `pet3d.js` の中で計算しています。数は相対 (0〜1) で、単位は付けません。1.0 より上の所も赤で塗ります。

- まとめ役: 強度信頼性と同じ v2 の式 (下)。節点は v2 と同じ、役の id から作った種で揺らした正二十面体の分割 (粗い 42 節点・80 要素、細かい 92・180)
- 設計役: 値は無い。形は角の丸い箱: 面の上の点 = 内側の箱 (半分の大きさ − r) に寄せた点 + r × 法線 (法線は元の点と寄せた点の差の向き)。半分の大きさ 0.96 × 0.92 × 0.84、r = 0.30
- パッケージ役 (箱, v8): 値は無い。積み木の色は、薄紫 = 役の色 `#8e6bbf` に `--paper` を 3 割、木の色 = `--s4` に `--paper` を 2.5 割混ぜてから `--ink-soft` を 2 割、セージ = `--s3` に `--paper` を 3 割混ぜてから `--ink-faint` を 2.5 割 (`pet3d.js` の `mixHex` で計算)。ガラスは役の色に白を 7 割 (不透明度 0.16、合格で光るとき 0.30 まで)、床の板は役の色に `--paper` を 5.5 割、辺の線は役の色に `--ink` を 5.5 割、食い違いの積み木は自分の色に `--miss` を 6.5 割
- パッケージ役 (組木と輪): 値は無い。棒の色は、横の棒が `--s4` (黄) と `--paper` の半々、縦の棒が `--s4` に `--s5` を 4.5 割混ぜてから `--ink-soft` を 3 割混ぜた茶、前後の棒が役の色 `#8e6bbf` と `--paper` の半々 (`pet3d.js` の `mixHex` で計算)。輪の別案は、鋼 (白に `--s1` を 1.2 割)・真鍮 (`--s4` に `--paper` を 2.5 割)・役の色 (白と半々) の金属
- 操安 (マルチボディ): 横加速度 a は v4 と同じ (待機などは 0.45 sin(2πt / 3.2)、作業中はダブルレーンチェンジで最大 1、食い違いは限界を超えたコーナー 1.3 + 0.06 sin(2πt / 1.6))。車体のロールの角 = 0.1 a (外へ傾く)。車輪とナックルは地面に残り、アームとばねは毎回ジョイントの位置どうしを結び直す。ばねの力 F = 0.5 − 0.35 a s (s = 小道具の側 +1・反対 −1、0.5 が止まっているときの分担)。F が 0.12 より小さいと内側の車輪が 0.1 (0.12 − F) / 0.06 だけ浮く (最大 0.1)。ばねの色が F の帯の色。形を見せるための簡単なモデルで、機構を解いた値ではない
- 動力: 進み c = (1 − tanh((d − r_f (1 + しわ)) / 0.08)) / 2 (d = 点火プラグからの距離、r_f = 火炎の半径、燃える間に 0 から燃焼室いっぱいまで一定の速さで大きくなる、しわ = 0.1 sin(5φ) sin(3θ))。温度 T = 0.1 + (T_b − 0.1) c、T_b = 0.82 + 0.16 (1 − d / d最大) (先に燃えた所ほど熱い)。食い違いは手前右の自己着火の点に 1.0 exp(−r² / 0.06) を足す
- 空力: 速さは v5 と同じ (表面は U sin θ (θ は面の法線と流れのなす角) × 断面の大きさによる増し (1 + 0.5 (r / r最大)²)、いちばん太い所で 1.5 U。まわりの流線は球を過ぎる流れ (ストークスの流れ関数) で道すじと速さを出す)。v6 では色をその速さからの圧力にした: 圧力係数 Cp = 1 − (V / U)² (ベルヌーイの式)。先端のよどみ点で 1、肩 (1.5 U) で −1.25。いちばん太い所より後ろは圧力が戻りきらない (境界層で失う分) として Cp を 0.08 で頭打ちにする (色は遠くの流れに近い黄) (尾の先に 2 つ目の赤い点を作らない)。色の値は (Cp + 1.25) / 2.25 で、先端が 1.0、肩が 0、遠くの流れが 0.56。食い違いのはく離した後ろは Cp = −0.45 + 0.08 sin(…) (低く平らな背圧)。形を見せるための簡単なモデルで、解いた値ではない
- 衝突: 当たった点からの距離 d、当たってからの時刻 τ で、残る応力 0.3 exp(−(d / 0.25)²) + 波 a exp(−((d − c τ) / 0.22)²) exp(−d / 3) + 0.5 秒あとの弱い波 (0.4 a)。c = 1.1 (作業中 1.6)、a = 0.85 (作業中は 0.75 から 1.1 へ)。へこみは当たった点から半径 0.3 の中を法線の向きに最大 0.055 押し込むだけで、目のある所は動かさない。減速度の線は sin²(π τ / 0.7) (1 + 0.15 sin 14τ) (0.7 秒で終わる) を最大で割った形
- 強度信頼性: 穴のある板を引っぱったときの応力集中の簡単なモデル (形を見せるためのもの。有限の板や厚さの影響は入れていない)。広い板の丸い穴 (半径 a) のまわりの応力の式 (材料力学の教科書にあるキルシュの解。出典の文献は確かめていない。穴のふちで σ_θθ = 1 − 2 cos 2θ、最大 3 になることは試験で見ている) で、穴の中心からの距離 r と荷重の向きからの角 θ、q = a² / r² として σ_rr = ½(1 − q) + ½(1 − 4q + 3q²) cos 2θ、σ_θθ = ½(1 + q) − ½(1 + 3q²) cos 2θ、τ_rθ = −½(1 + 2q − 3q²) sin 2θ (公称の応力 σ を 1)。ミーゼスの応力 √(σ_rr² − σ_rr σ_θθ + σ_θθ² + 3τ_rθ²) から、公称からの上がり分 v = L (σ_vm − 1) / (K_t − 1)、K_t = 3 (穴の上下のふちの値) を色にする (0 より下は 0)。穴の上下のふちが 1.0、荷重の向きのふちと遠くは 0 に近い。L は荷重の割合 (`loadFactor`)。食い違いは亀裂の先に 1.0 exp(−(d / 0.08)²) を足す
- まとめ役: v2 と同じ。体の重さ 1.0 を左右の足の付け根が半分ずつ受ける / 右手 (小道具の側) は小道具の重さ × 腕の長さ ÷ 0.11 を付け根に受ける (小道具の重さは役ごと 0.24〜0.5) / 左手は腕の重さ 0.06 で同じ式。1 つの荷重の値は 振幅 ÷ (1 + (距離 / 0.45)²)^1.5、体の自重の膜の項は 0.12 × √((1 − y) / (1 + y))。落ち着いた荷重の最大が 1.0 (右腕の付け根)。定数は `LOAD` と `PROP_MASS` (強度信頼性は v5 から使わない)
- 音振: 変位 w = A × Y(向き) × cos(2π f t) を法線の向きに足す。Y は 2 次のモード x² − y² (食い違いは 3 次 x (x² − 3y²))。色は各節点のモードの振幅 |Y| × A を、いちばん大きい振幅 0.17 で割った値 (形は揺れ、色は振幅の地図)。v6 のちらつき止め: f は待機などで 0.4、作業中 0.55、食い違い 0.45 (v5 は 0.62・1.25・0.8)。A は待機などで 0.09、作業中は 0.06 + 0.09 (1 − cos(2π t / 8.8)) / 2 (v5 は 4.4 秒ごとに 0.17 から 0.05 へ跳んでいた)。元の形の線は奥行きの試験をせずに描き、線の向き (元の形の法線) がカメラから離れるほど薄くする (v5 は面が線を前後にまたぐたびに線が出たり消えたりしていた)
- パッケージ役 (箱, v8): 升の一辺 0.54 で 3 × 3 × 3 = 27 升 (中の箱の半分の大きさ 0.81)。ガラスの壁は升から 0.025 外 (半分の大きさ 0.835)、辺の棒の太さ 0.026、ふたはその上 0.057。升を (i, j, k) = (左から右, 下から上, 奥から手前) で書くと、積み木は 下の板 (直方体 3 × 1 × 2、i 0〜2・j 0・k 0〜1)・前の L (手前の下の列 + 右の 1 升上)・上の T (手前の上の列 + 真ん中の奥へ 1 升)・真ん中の板 (直方体 2 × 1 × 2、i 0〜1・j 1・k 1〜2)・奥の L (真ん中の段の奥の列 + 右の手前へ 1 升)・上の L (上の段の奥の左 2 升 + 左の手前へ 1 升)・上の棒 (上の段の右の奥 2 升)。27 升をどれも 1 回ずつ占める (試験で見ている)。積み木は角の丸い箱 1 つか 2 つ (L と T は 2 つの箱が 1 升分重なる) の和で、箱は四方を 0.006 ずつ縮めて継ぎ目の線を作る。角の丸い箱は 6 面のそれぞれを (2k + 1) × (2k + 1) の四角に分け (k = 2)、丸めの帯の中の座標を (h − r) + r tan(j / k · π / 4) にとる (辺の弧が等しい角度で切れる)。同じ大きさの箱は 1 つの形 (と輪郭の殻) を使い回して向きだけ回す (4 種類)。辺の棒 12 本 (と ふたの 4 本) と角の玉 8 つは InstancedMesh。作業中に持ち上がる高さ 0.62 (1 升 + 0.08)、回る角は最大 π / 2、ふたが開いているときは後ろへ 1.72。食い違いの T は 0.4 上がって傾き (x に −0.1 rad・z に 0.09 rad)、ふたは T の奥のふちで止まる (1.2 秒ごとに 0.05 戻って当たり直す)。合格の T は 0.45 秒で 0.62 → 0 (だんだん速く)、ふたは 0.45〜0.95 秒で閉じ (だんだん速く)、光るのは 0.95〜1.75 秒。走るときの揺れ ± 0.005 は継ぎ目 (0.012) の半分より小さく、隣どうしが触れない。同じ URL で同じ画素になるように (GPU で撮るときも)、ガラスは裏の面・表の面の順の 2 回に分けて描き、壁とふたの板は辺の棒の内側で止め (棒がガラスの面を貫かない)、床は不透明の板 (役の色に `--paper` を 5.5 割) にしてガラス 2 枚越しに地面の柔らかい影が見えないようにし、腕の付け根は横の壁から 0.07 離している (どれも、そうしないと GPU で撮ると 2 回の絵が数画素だけ 1〜15 段ずれたため)
- パッケージ役 (組木, v7): 単位 u = 0.28。棒の断面は 2u × 2u、長さ 2.0 (真ん中の立方体 4u から両側へ 1.6u 出る)。横の 2 本は上下に、縦の 2 本は前後に、前後の 2 本は左右に並ぶ。真ん中の立方体を 4 × 4 × 4 の升に分け、2 本以上の棒が通る升は 1 本にだけ渡し (ほかの棒はそこが切り欠き)、どの升も 2 本の棒に入らないようにしている。どの棒も、長さの向きに 1 列の升 (外側の列) を必ず持つので 1 つにつながったまま。残りの重なる升は (i + j + k) で順に割り当てる。これは重なりの無い詰め方をコードで決めたもので、実際に組んで外せるパズルかは確かめていない。棒の形は、その棒の升の箱 (同じ棒の隣の升へ 1.5r 伸ばし、平らな面に継ぎ目の溝を作らない) までの距離から角を半径 r = 0.05 で丸めた面を、0.02 の格子の surface nets で面にしたもの。作業中に抜ける量は 0.36、食い違いで引っかかる位置は 0.34 (1.2 秒ごとに 0.05 押し込まれて戻る)、合格の収まりは 0.4 秒で 0.14 → 0 (だんだん速く)、光るのは 0.4〜1.2 秒 (棒の色で光る)、走るときのかたつきは ± 0.02
- パッケージ役 (輪の別案): 輪 k は座標面の中の楕円で、1 つ目の軸の半径 b = 0.5、2 つ目の軸の半径 a = 0.84、(x, y)・(y, z)・(z, x) の順 (ボロミアンの輪の作り方)。管の太さ 0.14。試験で 2 つの輪の芯の間が管の太さの 2 倍より離れている (輪どうしがめり込まない) ことを見ている
- 熱: 定常はフィン (まわりへ放熱) の解 T = cosh(mL (1 − s)) / cosh(mL)、mL = 1.3、s は下からの高さの割合。作業中は下から温める非定常の解 T = erfc(s / (2√(κt)))。食い違いは右の脇に熱だまりを足す

### 塗り方・線

- 節点の値をシェーダーで三角の中で線形に補間し、10 段で切ります (CAE の後処理のバンドのコンター)。四角の要素は 2 つの三角にしますが、対角の線は描きません
- 設計役は CAD の材質 (`cadMaterial`): 単色でなめらかに塗り、要素の辺ごとの重み (`aEdgeW`) で、フィレットの境の稜線 (重み 1、黒) とパラメータの線 (重み 0.5、薄い青灰) だけを描きます。要素の辺の線のオンオフには従いません
- 流れ・熱・走った線は、管の上を動く破線 (位相 = 道のり × 密度 − t × 速さ) で、色は線の上の値の帯の色です
- 輪郭は裏返した殻 (法線の向きに少し太らせた黒) で描きます。空力の体は半透明なので、中に生成りの芯を入れて輪郭の殻が透けないようにしています

## ビューアの開き方

`viewer.html` をブラウザで開きます (`file://` のままでよい)。three を jsDelivr から読むので、ネットにつながっている必要があります。

- 左の欄で 表示 (並び・1 体・大きさ)、役、状態、地 (生成り・夜)、要素の辺の線・節点のオンオフ、メッシュの細かさ (粗い・細かい)、カメラ (正面・斜め・横。押すとドラッグで回した向きを戻す)、自動回転、時刻を止める、を切り替えます
- 並びの表示でキャラを押すと、その 1 体の表示に移ります (ドラッグして回したときは移りません)
- 並びの表示は、前からの 10 体を 5 体ずつ 2 段、その下の 3 段目にモジュールの設計役 6 体 (v10) を並べます
- 1 体の表示と並びの表示は、マウスでどの向きにも回せます (TrackballControls。上下の角度の制限が無く、真上・真下からも見られる)。左ドラッグで回す、ホイール (と中ボタンのドラッグ) で寄る・離れる、右ドラッグで動かす。並びの表示では 16 体のカメラが同じ向きに回ります。回した向きはすぐ URL に写ります
- 「大きさ」の表示は、動画 N00 の 1 体の大きさ (184 px) とアプリの一覧の大きさ (48 px) で 16 体を並べた帯です
- 状態の釦は 待機・報告・合格・食い違い・作業中・走る・待ち・止められた です
- 「メッシュ」の欄の「軽い描き方 (小さく出す用)」で `lite` に切り替えます (作り直すのは形だけで、時刻・状態・カメラはそのまま)
- 1 体の表示では右上にコンターの凡例 (カラーバー) が出ます。題は役ごとの量の名前 (上の表)、10 段の色 (上が高い) と段の境の値 0.0〜1.0、その状態の説明、節点の値の最大と最小。並び・大きさの表示と、コンターの無い設計役とパッケージ役では出しません
- 役がパッケージ役のときだけ、左の欄に「パッケージ役の形」(箱・組木・輪) の釦が出ます
- 右下の「v10」が版の印です

### URL の引数

いまの表示はいつも URL に写っています。同じ URL を開けば同じ絵になります (姿と値は時刻 t と状態だけで決まり、時計や乱数は使いません。乱数は役の id から作った種で、毎回同じです)。

| 引数 | 値 | 既定 |
|---|---|---|
| `view` | `grid` (並び)・`one` (1 体)・`sizes` (大きさの帯) | `grid` |
| `role` | `lead`・`designer`・`packager`・`cae.handling` など (下の表) | `lead` |
| `state` | `idle` (待機)・`report` (報告)・`pass` (合格)・`mismatch` (食い違い)・`working` (作業中)・`run` (走る)・`waiting` (待ち)・`blocked` (止められた) | `idle` |
| `lite` | `1` で軽い描き方 (`create` の `lite: true`) | なし |
| `run` | `across` で走る状態を横に走り抜ける形にする (左の欄の「走るとき横に走り抜ける」) | なし (その場で走る) |
| `pkg` | `box` (箱)・`burr` (組木)・`rings` (輪)。パッケージ役の形 | `box` |
| `bg` | `paper` (生成り)・`night` (夜) | `paper` |
| `edges` / `nodes` | `0` で要素の辺の線 / 節点を消す (設計役のパラメータの線は残る) | `1` |
| `mesh` | `coarse`・`fine` | `coarse` |
| `cam` | `front`・`three` (斜め)・`side` | `three` |
| `spin` | `1` で自動回転 (向きは時刻だけで決まる) | なし |
| `orbit` | ドラッグで回したカメラ。注視点からのカメラの位置 x,y,z と、カメラの上の向き x,y,z (キャラの単位長)。並びの表示では縦横比 1 のときの距離。v3 の形 (方位,仰角,距離) も読む | なし |
| `pan` | 右ドラッグで動かした注視点 x,y,z | なし |
| `t` | 時刻 (秒)。あれば時刻を止めてその時刻の姿を描く | なし (動く) |

書き出し用に `window.petViewer = { ready, seek(t) }` を出しています。`ready` は three を読み終えて最初の絵を描いたら解ける Promise、`seek(t)` は時刻を止めて t の姿を描きます。

## 共通の部分

- 光: 部屋の環境光 (RoomEnvironment)、上からの主光 (柔らかい影)、後ろからの縁の光、体のシェーダーのフレネルの縁の光、足もとの接地の影。色は sRGB で管理し、トーンマップは色を崩しにくい Neutral を使っています
- 線: 要素の辺はシェーダーで重心座標から描き、画面の上で決まった太さ (キャラの大きさに合わせて 0.8〜2.4 px) になります。小さく出るときは辺を薄くし、節点の点を消して、色の帯が読めるようにしています
- 動き (`update(t, state)` は時刻と状態だけで姿が決まる): idle = 上下・呼吸・まばたき・アンテナの揺れ、report = 前に乗り出す、pass = 小さく跳ねて頭の上に ✓、mismatch = 体ごと首をかしげて頭の上に ?、working (作業中) = 役ごとの体の動き (上の表)・目が小道具を見る。run (走る) = 足を交互に前後へ振り (股の付け根で回す、1 歩の往復 = 0.6 秒、振れ幅 0.8 rad)、体が 1 往復に 2 回弾み (高さ 0.09、足がまっすぐ下のとき低く、開いたとき高い)、少し前に傾き (0.17 rad)、腕は足と逆に振る。その場で走るのが既定で、横に走り抜ける形 (`run: "across"`、ビューアは `run=across`) では右へ少し向いて、7.2 の幅を 3.0 秒で横切ってまた左から出る。操安は車輪も回る。どれも時刻 t だけで決まる。形の変わる体 (衝突・音振・設計役) では、目とアンテナを毎回その時の面の上に置き直します
- 吹き出し (✓・?・…・止まれの印): アンテナの玉より上、少し右に出し、跳ねるときは体と一緒に上がります。`update` の 4 つ目に `{ mark: false }` を渡すと、どの状態でも印を出しません (画面の側で CSS の札を重ねるとき二重にしないため)

## v9: 待ち・止められた・軽い描き方

### 待ち (`waiting`)

答えを待つ間ずっと続く、落ち着いた動き。急な動きはありません。数は `pet3d.js` の `WAIT`。

- 体重を左右の足へゆっくり移す: 傾き 0.075 sin(2πt / 5.2) rad と、体を荷重の側へ 0.035 ずらす
- 8 秒ごとの 1 周の中で、2.2〜4.4 秒に上を見る (瞳が上へ 0.05、体が少し後ろへ 0.07 rad)、4.8〜7.6 秒にあたりを見る (左、次に右へ 0.22 rad 向き、瞳もそちらへ)。どちらも sin² のなめらかな山で、0 から入って 0 へ戻る
- アンテナが横へ 0.3 rad・前へ 0.14 rad 垂れ、ゆっくり揺れる (3.4 秒と 4.1 秒の周期)
- 頭の上に生成りの札と点 3 つ (「…」)。0.45 秒ごとに灯る点が 0 → 1 → 2 → 3 個と増えてまた 0 に戻る。灯った点はインクの色で少し大きく、消えた点は `--ink-faint` で小さい

### 止められた (`blocked`)

hooks に止められたと分かる動き。数は `pet3d.js` の `BLOCK`。u = 止められてからの秒数。

- u = `t − o.since` (`update(t, "blocked", camera, { since })`)。`o.since` を渡さないときは u = t mod 3.0 (3 秒ごとにくり返す)。u が負なら 0
- u = 0〜0.1 秒: びくっと後ろへ 0.13 引き (カメラから離れる向き)、後ろへ 0.16 rad 反り、体が 6 % 縮む。その後 0.6 秒までに 0.6 の深さまでなめらかに戻って止まる (0.8 秒からあとは姿が変わらない)
- 0.08〜0.8 秒: 小さな震え (11 回/秒、0.15 秒で消える)
- 0.05〜0.4 秒で空いている手 (左) を前へ 1.3 rad 出し、小道具の手も 0.45 rad 上げる。アンテナは 0.1 秒で後ろへ 0.6 rad 曲がる。目が 16 % 大きく開き、まばたきしない
- 固まる: 0.3 秒で上下と呼吸とアンテナの揺れが止まり、体そのものの動き (コンター・流れの線・機構・吹き流し) も 0.3 秒の時刻で止まる
- 頭の上に赤い止まれの印 (`--miss` の丸に白い横棒、縁はほかの札と同じ黒い殻)。0〜0.3 秒で 0.35 倍から少し大きく出て 1 倍に収まり、震えと一緒に少し揺れる

画面の poseTime に合わせる方法: 画面は idle 以外で `poseTime = ceil(since / hop + 1) × hop + (t − since)` を `t` として渡す (`hop` = layout.json の `n00.motion.hop_period_s`)。止められた瞬間の pose の時刻は `T0 = ceil(since / hop + 1) × hop` なので、`update(poseTime, "blocked", cam, { since: T0 })` と渡せば u = t − since になり、反応の 3 秒のはじめにびくっとが来ます。`o.since` を使わない場合は、blocked のときだけ hop の代わりに 3.0 (`BLOCK.react`) を使って `ceil(since / 3 + 1) × 3 + (t − since)` を渡せば、u = pose mod 3 = t − since になります。

### 軽い描き方 (`lite`)

高さ 60 px 以下で出すとき用。`create(THREE, { role, lite: true })`、または作ったあとで `pet.setOptions({ lite: true })` (同じ `pet.group` の中で作り直す。地の色・辺・節点・`setPixelScale` の値は引き継ぐ)。`lite` を付けないときの絵は v8 と画素まで同じです (試験と、10 役 × 6 状態 × 2 つの t の画素の比べで見た)。減らすもの (数は `pet3d.js` の `LITE` と `liteThree`):

- 丸い形の分割: 球・円柱・円錐・カプセル・輪・管の分割の数を 0.45 倍にする (下限: 球 8 × 6、円柱・円錐 8、カプセル 2 × 6、輪 4 × 12、管 8 × 4。下限以下の数はそのまま。六角のボルトや 5 角の流線の管は変わらない)。目の白目は 32 × 20 → 14 × 9 になる。体のメッシュ (要素・節点) は変えない
- 縁取り: 幅 0.02 より細い殻 (小さな部品の縁取り) を作らない。体・目・アンテナの玉・小道具・札の縁取りは残す
- 描く回数: 足と足先、腕と手を 1 つの形にまとめる (同じ材質・同じ親で、別々には動かない。1 体で 4 回減る)。手の正二十面体は分割なし (80 → 20 個)
- 節点の点を作らない (60 px ではもともと見えない)
- 影を落とす部品: 外接球の半径が 0.22 より小さい部品は影の地図に描かない (足もとの接地の影はそのまま)

`pet.cost()` は、いまの姿 (`update` のあと) で描く量を返します: `{ calls, triangles, shadowCalls, shadowTriangles, hulls, meshes, lite }`。`calls` と `triangles` は見えているメッシュの描く回数と三角の数 (殻を含む。InstancedMesh は 1 回で三角 × 数)、`shadowCalls` と `shadowTriangles` は影を落とすものの分。待機 (t = 1.0) の 10 体の合計は lite なし 444 回・143,246 個、lite あり 367 回・56,422 個 (三角は 4 割)、影を落とすものは 181 回・28,356 個 → 118 回・20,208 個。描き時間は試験の外で測った (ソフトの WebGL の SwiftShader、高さ 60 px、10 体を 1 体ずつ、画面の PetStage と同じ設定 = antialias・PCFSoftShadowMap・影の地図 256 px): 1 コマ (10 体) の中央値が lite なし 49.3 ms、lite あり 23.7 ms
