# HIRAKU のペット (3D)

HIRAKU のエージェントの役ごとのキャラ (ペット) を three.js で 3D にしたものと、見ながら直すための専用ビューアです。版は v2 (v1 から: 体をローポリの平らな面にし、コンターを荷重から計算する値の帯にし、凡例を付け、吹き出しをアンテナの玉から離した)。

| ファイル | 中身 |
|---|---|
| `pet3d.js` | キャラの組み立て。ふつうのスクリプト (ES module ではない) で `window.HirakuPets = { ROLES, STATES, FRAME, BANDS, STOPS, BAND_COLORS, LOAD, PROP_MASS, loadFactor, create(THREE, opts) }` を出す。three は呼ぶ側が渡す。`create` の返す物は `update(t, state, camera)` のほかに `contour(t, state)` (荷重の割合・荷重のかかり方・節点の値の最大と最小) と `field` (節点の座標と値) を持つ |
| `viewer.html` | 専用のビューア。three r170 と OrbitControls・RoomEnvironment を jsDelivr から読み、`pet3d.js` に渡す |

平面の絵 (`promo/screens/pets.js`、動画 N00 で使用) はそのまま残してあり、ここでは参考にしただけです。

## ビューアの開き方

`viewer.html` をブラウザで開きます (`file://` のままでよい)。three を jsDelivr から読むので、ネットにつながっている必要があります。

- 左の欄で 表示 (並び・1 体・大きさ)、役、状態、地 (生成り・夜)、要素の辺の線・節点のオンオフ、メッシュの細かさ (粗い・細かい)、カメラ (正面・斜め・横)、自動回転、時刻を止める、を切り替えます
- 並びの表示でキャラを押すと、その 1 体の表示に移ります。1 体の表示はドラッグで回せます
- 「大きさ」の表示は、動画 N00 の 1 体の大きさ (184 px) とアプリの一覧の大きさ (48 px) で 10 体を並べた帯です
- 1 体の表示では右上にコンターの凡例 (カラーバー) が出ます。並び・大きさの表示では出しません
- 右下の「v2」が版の印です

### URL の引数

いまの表示はいつも URL に写っています。同じ URL を開けば同じ絵になります。

| 引数 | 値 | 既定 |
|---|---|---|
| `view` | `grid` (並び)・`one` (1 体)・`sizes` (大きさの帯) | `grid` |
| `role` | `lead`・`designer`・`packager`・`cae.handling` など (下の表) | `lead` |
| `state` | `idle`・`report`・`pass`・`mismatch`・`working` | `idle` |
| `bg` | `paper` (生成り)・`night` (夜) | `paper` |
| `edges` / `nodes` | `0` で要素の辺の線 / 節点を消す | `1` |
| `mesh` | `coarse`・`fine` | `coarse` |
| `cam` | `front`・`three` (斜め)・`side` | `three` |
| `spin` | `1` で自動回転 (向きは時刻だけで決まる) | なし |
| `orbit` | 1 体の表示でドラッグしたときのカメラ (方位,仰角,距離。ラジアンと単位長) | なし |
| `t` | 時刻 (秒)。あれば時刻を止めてその時刻の姿を描く | なし (動く) |
| `ui` | `0` で左の欄を隠す (書き出し用) | なし |

例: `viewer.html?view=one&role=cae.crash&state=pass&bg=night&t=1.2`

書き出し用に `window.petViewer = { ready, seek(t) }` を出しています。`ready` は three を読み終えて最初の絵を描いたら解ける Promise、`seek(t)` は時刻を止めて t の姿を描きます。

## キャラの作り方

- 体: 正二十面体を分割した球 (three の `IcosahedronGeometry`、粗い = 分割 1 で節点 42・要素 80、細かい = 分割 2 で節点 92・要素 180) を節点と三角の要素に組み直し、てっぺんの節点 (アンテナの根もと) 以外を少しずつずらしています。ずらし方は役の id から作った種の乱数で、毎回同じです。形は少し下ぶくれの楕円体です。法線は要素ごとに 1 つ (面ごとに平ら) で、光で面が 1 枚ずつ見えます。目は乗っている面の上に置き、足・腕・手・アンテナの玉も角の残る粗い形にしています
- コンター (相対の応力) の値: 節点ごとに、キャラにかかる荷重から計算します。形を見せるための簡単なモデルで、解いた値ではありません。定数は `pet3d.js` の `LOAD` と `PROP_MASS`
  - 荷重: 体の重さ 1.0 を左右の足の付け根が半分ずつ受ける / 右手 (小道具の側) は小道具の重さ × 腕の長さ ÷ 0.11 を付け根に受ける (小道具の重さは役ごと 0.24〜0.5) / 左手は腕の重さ 0.06 で同じ式。各荷重は付け根にいちばん近い節点にかけます
  - 1 つの荷重の値: 振幅 ÷ (1 + (距離 / 0.45)²)^1.5。付け根で高く、離れるほど下がります
  - 体の自重の膜の項: 0.12 × √((1 − y) / (1 + y)) (y は高さを −1〜1 にしたもの。足の付け根より下は一定)。てっぺんで 0 になります
  - 足し合わせて、落ち着いた荷重 (`pass` など) の節点の値の最大が 1.0 になるように割ります。いちばん高いのは右腕の付け根、てっぺんは 0.15 未満 (試験で見ている)
- 状態との紐づけ: `idle`・`report`・`pass` は落ち着いた荷重。`working` (解析中) は荷重を 0 から 10 回の増分で 1.0 まで上げ (0.32 秒ごと、3.2 秒で 100 %)、4.4 秒ごとに始めから。値は荷重に比例するので、付け根から色が広がります。`mismatch` (食い違い) は「予測では両足で半分ずつ、実際は体の重さが左足に全部かかり、付け根の切欠きで 4 倍」という別の荷重で、左足の付け根に赤い集中が出ます (最大は 1.0 を超え、超えた所も赤)
- 塗り方: 節点の値をシェーダーで三角の中で線形に補間し、10 段で切ります。帯の境目 (等値線) が要素の中を横切る、CAE の後処理のバンドのコンターの見え方です。光の当たり方で色がずれすぎないよう、光の色と帯の色を半々に混ぜています
- 凡例: 1 体の表示の右上に、10 段の色 (上が高い) と段の境の値 0.0〜1.0 の目盛り、「相対の応力」の題、荷重の割合 (解析中は増分)、節点の値の最大と最小を出します。単位は付けません
- 線: 要素の辺はシェーダーで重心座標から描き、画面の上で決まった太さ (キャラの大きさに合わせて 0.8〜2.4 px) になります。小さく出るときは辺を薄くし、節点の点を消して、色の帯が読めるようにしています。輪郭は裏返した殻 (法線の向きに少し太らせた黒) で描きます
- 光: 部屋の環境光 (RoomEnvironment)、上からの主光 (柔らかい影)、後ろからの縁の光、体のシェーダーのフレネルの縁の光、足もとの接地の影。色は sRGB で管理し、トーンマップは色を崩しにくい Neutral を使っています
- 動き (`update(t, state)` は時刻と状態だけで姿が決まる): idle = 上下・呼吸・まばたき・アンテナの揺れ、report = 前に乗り出す、pass = 小さく跳ねて頭の上に ✓、mismatch = 体ごと首をかしげて頭の上に ?、working = 荷重が増分で増える・目が小道具を見る
- 吹き出し (✓ と ?): アンテナの玉より上 (玉のてっぺんから 0.1 ほど空けた高さ)、少し右に出し、跳ねるときは体と一緒に上がります。首をかしげても横から見ても玉と重なりません

## 試験

`promo/tests/test_pets.py`: `pet3d.js` の役が 10 体でアプリの役の id (`hiraku/contract/hiraku.schema.json`) とそろっていること、色がリポジトリの値と同じこと (コンターの `BANDS`・`STOPS` が `web/js/colormap.js` と同じこと)、メッシュの細かさ、版の印、姿を決めるところで時計や乱数を使っていないこと。playwright とネットがあるときだけ、ビューアを開いて次も見ます (無ければ飛ばします): `window.petViewer.ready` が解けること、`BAND_COLORS` が `colormap.js` の計算と同じで、凡例が 10 段 (上が高い)・目盛り 11 本で、並びの表示では凡例が出ないこと、解析中の荷重が 0 から 1 へ増えること、全 10 体 × 2 つの細かさで節点・要素の数、落ち着いた荷重の最大 1.0 が右腕の付け根の節点・てっぺんが 0.15 未満・食い違いの最大が左足の付け根の節点にあること。
